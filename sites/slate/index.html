Slate

A lightweight, native word processor for Linux.

Part of Cronkite · Written in Rust

Not released yet

Slate is in development and has no release to install yet. Today it opens .docx, Markdown, and plain-text files in a read-only viewer; editing and saving come next. When it ships, its install instructions will be on this page and on cronkite.cc.

Available today: Bricks

Bricks, Cronkite's spreadsheet, is ready now. It opens gigabyte CSV files in a blink and edits .xlsx workbooks. Install it for your user, without sudo:

curl -fsSL https://bricks.cronkite.cc/install.sh | sh

Requirements, updates, and uninstalling: cronkite.cc.

Source

Slate is developed in the open with the rest of Cronkite: github.com/avdrav1/cronkite.
