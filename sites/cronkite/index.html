Cronkite

A fast, native office suite for Linux. No subscriptions, no browser tab, no waiting.

Spreadsheets · Documents · Presentations · Written in Rust

The apps

Each app installs and runs on its own. Install what you need.

Install

One command per app, for your user only. No sudo, no package manager. Paste it into a terminal; then start the app from your app menu.

Bricks

curl -fsSL https://bricks.cronkite.cc/install.sh | sh

The command is bricks. CSV and TSV files open with it. Download page: bricks.cronkite.cc.

Slate

curl -fsSL https://slate.cronkite.cc/install.sh | sh

The command is slate. Word documents (.docx) and Markdown (.md) open with it, and it offers to open plain text. Download page: slate.cronkite.cc.

Frame

Not released yet. When it is, it installs the same way, from frame.cronkite.cc, and .pptx files will open with it.

What an installer does

  1. Downloads the app's latest release and checks it against its published sha256. If the checksum doesn't match, nothing is installed.
  2. Puts the app (bricks, slate) in ~/.local/bin, and its menu entry and icon in ~/.local/share.
  3. Makes it the default app for its files (above), so double-clicking one opens it. Other apps' defaults for other files are kept.

Requirements

An x86_64 Linux system with GTK 4.14 or newer. GNOME desktops already have it. Tested on Arch, Ubuntu 24.04, and Fedora, and newer releases of each. If GTK 4 is missing, the installer tells you how to get it:

DistributionInstall GTK 4
Arch, Manjaro, EndeavourOSsudo pacman -S gtk4
Ubuntu 24.04+, Debian 13+sudo apt install libgtk-4-1
Fedorasudo dnf install gtk4
openSUSEsudo zypper install libgtk-4-1

Update

Run the app's install command again. It replaces the old version and keeps your settings and recent files.

Uninstall

curl -fsSL https://bricks.cronkite.cc/install.sh | sh -s -- --uninstall
curl -fsSL https://slate.cronkite.cc/install.sh | sh -s -- --uninstall

Removes the app, its menu entry, and its file defaults. Your files are untouched.

Prefer a tarball?

Each app's download page has its latest release as a .tar.gz, with its version, size, and sha256: Bricks, Slate.
